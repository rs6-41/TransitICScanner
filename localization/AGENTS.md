# 翻訳CSVの作業規定

ルートの `AGENTS.md` を継承する。実行手順と列の定義は [README.md](README.md) を参照する。

- 翻訳を編集するときは、対象となるCSVとカタログの組を確認する。キーの綴り・空白・書式指定子を維持し、未指定の言語は既存の文言を尊重する。
- CSVのセルを編集した後は、`--dry-run`、反映、カタログ差分確認の順に実施する。反映後に再度 `--dry-run` を実行し、両カタログの変更対象が0件になることを確認する。
- Xcode側で編集した場合は、CSVの未反映変更を確認してから再出力する。CSVとカタログの両側に変更がある場合は、差分を突き合わせてから同期する。
