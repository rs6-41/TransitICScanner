# 補助スクリプトの規定

ルートの `AGENTS.md` を継承する。

- スクリプトはリポジトリルートから再現可能に実行できるようにし、入力パスは引数または `__file__` から解決する。
- Pythonの命名はsnake_case。小規模な検証は標準ライブラリを優先する。Swiftの補助スクリプトは共通のswift-format設定を使う。
- Swiftコードを抽出するテストは本番ソースを使う。検証用に解析処理やモデルを複製しない。改名・移動時は抽出箇所も更新する。
- 生成物は一時ディレクトリに置く。既存の翻訳変換スクリプトのようにファイルを書き換えるものは、入力・出力・バックアップの仕様をREADMEに記載する。
- fixtureは合成値または明示的な公開サンプルを使う。実利用者のカード番号・IDm・履歴をテストへ持ち込まない。
- 命名チェックの例外は保存・外部互換性が必要な識別子に限り、根拠を共通AGENTS.mdに記載する。
- コマンドと対象を追加・変更したら `script/README.md` と `doc/dev/README.md` の検証手順を更新する。
