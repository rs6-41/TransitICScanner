# リポジトリ内スキルの保守規定

ルートのAGENTS.mdを継承する。各スキルは `SKILL.md` を入口とし、追加資料・成果物テンプレート・検証コードを必要な工程だけから参照する。

- `transit-card-workflow/`：調査/iOS Issue、調査資料からの仕様書、仕様書からの実装。
- `transit-localization/`：指定した1言語からの翻訳補完とJSON内の文脈コメント。
- 命名・カード仕様・保存互換性の規定は既存AGENTS.mdを参照し、スキル内に別の正解を作らない。
- GitHubへの投稿・実機アクセス・公開等の外部操作は、その利用時のユーザー依頼に従う。スキルの作成・読込自体を外部操作の許可と扱わない。
- テンプレートの変数は生成時に埋め、未確定値は未確認として記録する。過去カードの仕様値・実利用者の情報を新カードのfixtureとして流用しない。
- スキルのUIメタデータは `agents/openai.yaml` に置き、必須のname/descriptionと整合させる。
- Pythonはsnake_caseと標準ライブラリを基本とし、リポジトリ内ファイルは呼出元のcwdに依存せず解決する。生成物は一時ディレクトリへ置く。
- 本番ソースを抽出する回帰テストは処理を複製せず、改名・移動に合わせて参照を更新する。SwiftDataテストは合成データと一時ストアだけを使う。
- 指示や検証コードを変更したら、参照リンク・テンプレート・該当する検証の挙動を確認する。メタデータ検証だけを実装や翻訳の意味の検証として扱わない。
